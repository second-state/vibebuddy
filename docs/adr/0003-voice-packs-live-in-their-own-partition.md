# 语音包放独立分区、走串口协议写入

用户要在 Mac 上挑播报音色，而五句 PCM 一直是编译进固件 app 分区的。我们决定新增一个 `voices` 数据分区存语音包，固件启动时读它、空则回落内置音色；换音色由 Mac 分块经现有串口协议发过去、固件自己写分区，不复位、不用 esptool。

## 被拒绝的方案

每种音色各编一个固件，换音色即烧固件：把固件版本和音色纠缠在一起，新增音色要重发所有固件，且换音色变成一次刷机。Mac 播放时实时传音频：违背"语音资产在固件里、番茄钟不依赖 Mac"的既有决定，桥接 115200 波特也传不动。

## 后果

分区表要改一次，老固件检出要删 `sdkconfig` 重建。写入在桥接下要三分钟，所以包头最后写，半途拔线等于没写。固件升级不得抹 `voices` 分区。
