# Vibe Buddy 第一版自研 PCB 设计输入

状态：设计输入草案，已有部分原理图草稿，已有初步 PCB 布局，但尚无可下单的生产文件。

## 设计工具与工程位置

- 用户已确定使用 KiCad 设计原理图和 PCB，嘉立创负责制造及贴片。
- 工程目录：`hardware/rev-a/`，可编辑工程与设计资料纳入仓库版本管理。
- 用户已安装 KiCad 10.0.6，命令行工具与符号、封装、3D 模型库已确认可用。九页原理图草稿已绘制电路并通过解析与导出，ERC 为 0 错误、0 警告；USB 功耗/浪涌和屏幕机械输入仍未闭环，已有未布线 PCB，DRC 尚未通过。具体进度见工程目录 README。
- 制造交付物包括 Gerber、钻孔、BOM、贴片坐标及装配说明；不能将草稿目录或未验证文件作为生产包。

## 已确认的目标

- 保留正点原子 BOX、面包板两种已有固件支持；自研板另有硬件配置。
- 不接模型、不开发语音对话；保留麦克风硬件和已通过的录音能力。
- 第一版自研 PCB 纳入 BOX3 参考音频架构：模拟麦克风 + ES7210 采集、ES8311 播放、NS4150B 功放和外接扬声器，包含播放信号回送采集芯片的 AEC 参考通路。硬件纳入不等于 AEC 软件或语音打断已经完成。
- 屏幕显示、扬声器播放、麦克风采集、USB 与 App 通信已获得本轮用户实机确认。
- 首批产品目标为 20～50 台，先做少量工程样机验收，再决定试卖批次。
- 对外只保留一个 USB-C、三个业务按键和一个独立复位键；不安装 TF 卡座、额外 USB、UART 扩展插座及通用扩展排针。屏幕、麦克风、扬声器和 Wi-Fi 保留。

## 建议的第一版范围（待冻结）

- ESP32-S3 模组焊接到自研主板，保留 Wi-Fi 能力；不把整块 GOOUUU 开发板装到量产主板上。
- 唯一 USB-C 同时供电、原生 USB 通信和下载；暂按无电池方案设计。
- 主板包含电源、音频功放、三个业务按键和一个独立复位键；不额外增加外露下载键。板内预留下载模式、复位及必要调试测试点，具体电路和故障恢复流程在原理图阶段确认并验证。
- 不依赖 TF 卡存储；现有声音与界面资源继续按板载 Flash 方案规划，后续核算固件、资源及升级所需容量。录音验证不要求设备长期保存录音。
- 正式版按 BOX3 的 2.4 英寸裸屏参考设计推进（用户最新确认）；1.54 英寸面包板屏仅作验证。用户明确拒绝带底板模块，要求裸屏。BOX3 官方电路中的 TFT024B579-B0（30 针、0.5mm、下接 FPC）作为当前电气参考，不再要求确认与旧 BOX 同款；仍须核定机械规格；不能套用 ATK-MD0240/TFT024B462 的 29 针资料。见[屏幕料号调查](lcd-model-research.md)。扬声器通过接口连接。
- 麦克风采用模拟采集路线，须确认完整料号、偏置、灵敏度、收音孔与机械安装方式；不直接沿用面包板数字麦克风的接法。音频架构依据见[音频调查记录](box-audio-research.md)。
- 板形以易调试为先，保留固定孔；尺寸和元件位置仍需和屏幕、按键、扬声器装配配合。

## 布板前需要补齐

1. 模组完整料号、厂家数据手册、推荐焊盘和天线净空；“N16R8”是存储容量标识，不能用来推断不同厂家的模组封装兼容。
2. 屏幕按 BOX3 的 TFT024B579-B0 参考设计；核定实际供货屏幕的排线、背光和机械尺寸后冻结屏幕座及位置。此前 ATK-MD0240/TFT024B462 资料只保留为调查历史，不能用于当前屏幕的封装或尺寸。
3. 模拟麦克风完整料号、规格书与封装；ES7210、ES8311、NS4150B 的完整订购型号、供应情况、供电与时钟要求。核对播放参考信号幅度与采集通道配置，重新做录放音和参考通道验证。
4. 扬声器标称阻抗和额定功率；据此选择功放供电和输出能力，不能把低音量 3V3 测试当作最大音量设计依据。
5. 三个业务按键与一个复位键的操作方向、位置与封装；确认无外露下载键时，通过板内测试点进入下载模式的恢复方案。
6. 板框、固定孔和接口出线方向。3D 打印可以容纳修改，但不替代机械尺寸确认。

## 设计与交付顺序

1. 冻结器件和接口，完成 BOM 初稿及供应情况检查。
2. 原理图：USB-C CC、电源预算/稳压/去耦、保护、复位下载、音频与按键。
3. PCB：核对封装，处理天线净空、USB 走线、功放回流和麦克风噪声/声孔；做 ERC、DRC 与人工复核。
4. 导出可编辑 EDA 工程、Gerber/钻孔、BOM、贴片坐标及装配说明；平台匹配料号和生产稿后再下单。
5. 少量工程样机：上电电压、下载、USB、屏幕、按键、录放音、供电负载、Wi-Fi 和组合运行验证。
6. 修订后再考虑 20～50 台试卖，不能从面包板通过直接跳到整批生产。

嘉立创 PCB 加 SMT 流程需要板文件、BOM 和坐标文件，参见[官方贴片下单流程](https://www.jlc.com/portal/server_guide_19858.html)。平台制造检查不等于功能验证。
