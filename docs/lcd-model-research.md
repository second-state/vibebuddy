# 正点原子 2.4 英寸屏幕料号调查

调查日期：2026-09-18。当前决定：正式产品按 BOX3 裸屏参考设计推进，不再要求确认与旧 BOX 同款；1.54 英寸面包板屏仅作验证。下文独立模块调查为历史记录，当前依据见末节。

## 结论与证据边界

- 客服推荐的[独立屏幕商品](https://detail.tmall.com/item.htm?id=768663566580)与 **ATK-MD0240** 的尺寸、分辨率、驱动和接口规格一致，属于高度匹配的模块型号。
- `alientek-module/LCD-module_2.4-inch_ATK-MD0240` 公开资料包中的屏幕规格书明确写出 **深圳市优智景科技有限公司（UNVISION），TFT024B462**。这是有厂商规格书支持的裸屏候选，不是根据 ST7789 猜出的料号。
- **尚不能证明用户 ATK-DNESP32S3-BOX V1.1 的当前生产批次使用同一裸屏**。缺少该 BOX 的 BOM、实物屏幕排线料号或厂商对该料号的明确确认。不得将候选写成已冻结生产物料。
- 未验证裸屏库存、价格、最低采购量及长期供货；模块零售价不能当作裸屏成本。

## 设计前需解决的资料问题

1. 仓库 README 写模块最大 50 mA，但裸屏规格书背光典型为 80 mA；不能据前者直接冻结供电预算，需核对背光实际驱动电流。
2. README 的 32 Pin 数据位映射与原理图不一致：README 将 12～27 顺序写为 D0～D15，原理图为 12=D15、27=D0。应核实实物/最新生产图，而非照 README 接线。
3. 裸屏机械图端点标为 1～29，间距为 1.00 mm，但尺寸公式写有 `P1.0*(32-1)=28.00`，算式存在笔误。不得由该错误公式制作最终焊盘。
4. 29 引脚裸屏焊接端、32 Pin 转接板接口、2×4 SPI 排针是三个不同连接层级；必须区分。

## 下一步

## 2026-09-18：BOX3 裸屏参考更新

用户要求直接使用 BOX 同款裸屏，不接受 ATK-MD0240 模块，并允许参考 BOX3。BOX3 官方 LCD 教程原理图标为 **TFT024B579-B0**，配 30 针、0.5mm 间距、下接 FPC 座；这一接口与此前独立模块 TFT024B462 的资料不同，禁止混用。

来源：[官方 BOX3 LCD 文档固定版本](https://github.com/openedv/openedv-wiki-boards-dnesp32s3b3/blob/c6f9797b64aef2666547206b4b274017d6d28a3d/example-idf/lcd.md)，[官方电路图](https://github.com/openedv/openedv-wiki-boards-dnesp32s3b3/blob/c6f9797b64aef2666547206b4b274017d6d28a3d/example-idf/img/19.png)。本地原图：`hardware-reference/atk-box3/19.png`。

Rev A 当前仅采用其电气映射：1 LEDA、2 LEDK/GND、3 GND、4/5 3V3、6/7 3V3、8 GND、9 RESET、10 CS、11 SCLK、12 DC、13 GND、14 MOSI、15–30 GND。引脚 11/12 必须按 SPI 模式连线，不按并口功能名猜测。

仍未取得可信的 TFT024B579-B0 裸屏承认书，外形、排线厚度、出线位置、背光电流尚未冻结。没有给屏幕座指定生产封装，也没有生产板框。用户后续明确“参考 BOX3 就行”：旧 BOX 同款证明及客服链接不再是继续设计的前提。继续依据 BOX3 官方资料核定屏幕接口和布局；原始资料未给出的尺寸仍须标明未确认，不能以此授权推断未知规格。
