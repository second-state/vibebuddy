# 小灯灵：AgentBeacon 的实体宠物

## 产品定义

小灯灵不是 Codex 宠物的复制品，而是 AgentBeacon 的原创像素角色。Codex、其他本地 Agent、训练任务和 CI 都可以驱动同一只宠物。角色动画、表情和声音在盒子上运行；Mac 只发送稀疏的状态事件。

## 状态语言

| 状态 | 画面 | 语音 |
| --- | --- | --- |
| 空闲 | 呼吸、眨眼 | 无 |
| 工作中 | 浮动、`>` 与循环点阵 | 无 |
| 需要确认 | `!?`、橙色强调 | “需要你确认”一次 |
| 完成 | 开心、跳动、绿色 | “任务完成”一次 |
| 失败/阻塞 | X 眼、下沉、红色 | “任务遇到问题”一次 |

语音是注意力补充，不是持续状态通道；因此工作中和空闲保持安静。

## 多任务卡片

- 最多显示 3 张活动任务卡，最近活动的任务在最上。
- 卡片顺序表达时间；小灯灵的全局表情表达最需要用户处理的状态。
- 全局优先级为“需要确认 > 工作中”。因此旧任务等待确认时，即使上方出现了更新的工作任务，小灯灵仍显示需要确认。
- V1 只显示项目名和状态。Codex 官方 Hook 不提供 UI 中的自动任务标题；默认不读取 prompt 或 transcript 来猜标题。

这个拆分比简单照搬桌面 UI 更适合小屏：卡片回答“有哪些任务”，宠物回答“我现在最需要你注意什么”。
