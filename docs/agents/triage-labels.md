# Triage 标签

各技能用五个规范的 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库的标签       | 含义                         |
| -------------------------- | ------------------ | ---------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估这个 issue     |
| `needs-info`               | `needs-info`       | 等报告者补充信息             |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可交给无人值守的 Agent |
| `ready-for-human`          | `ready-for-human`  | 需要人来实现                 |
| `wontfix`                  | `wontfix`          | 不会处理                     |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标签」），用表中右列对应的字符串。

若你实际用的词汇不同，改右列即可。
