# 休闲模式

氛围小助手有三个模式，每个名字说的都是它此刻在替你做什么：**值班**盯着 Agent，有事叫你；**番茄钟**给你计时；**休闲**是值班时没事干够久了，自己去玩。值班和番茄钟之间由 K1 切换；休闲不用切，它自己来，也自己走。

## 无聊度

休闲不是一个开关，是一个很小的情绪模型：空闲时间越长越无聊，一有事就清零。行为按档位来：

| 空闲时长 | 档位 | 行为 |
| --- | --- | --- |
| 0 到 5 分钟 | 待命 | 值班画面里现有的呼吸、眨眼、轮播战绩 |
| 5 到 30 分钟 | 无聊 | 进入休闲模式；每 20 到 40 秒随机演一段小剧目，其余时间站着呼吸 |
| 30 分钟以上 | 困倦 | 以睡觉为主，画面整体转暗，隔两到五分钟说一段梦话或被自己吓醒一次 |
| 夜里 23 点到早上 7 点，空闲 90 分钟以上 | 熄灯 | 关掉背光，屏幕全黑 |

**空闲按状态算，不按消息算。** beacond 去重，一个任务跑二十分钟设备可能一条消息都收不到，但它明明在工作。所以只有同时满足这些条件才累计空闲：氛围小助手主状态是空闲且没有任务卡、番茄钟没在走、链路没断、最近没有按键。番茄钟待开始或暂停不算在走。待开始的一屏静止的 `25:00` 和值班空闲一样无聊，五分钟就切回值班、接着进休闲；暂停的是用户有意停在那里的，放了三十分钟没人动才当人已经走了。第一版两者都等三十分钟，实际用下来 dragon 在待开始的番茄钟前等不到精灵出来玩，改成现在这样。

**有事立刻回来。** Agent 任何一条状态消息、任何一个按键，都把无聊度清零并回到值班。按键是唤醒并执行，不是只唤醒：休闲没有遮住任何需要先看一眼再决定的东西，K2 要按两下才能打开来源只会显得设备迟钝。K1 短按从休闲直接去番茄钟；K0 从休闲直接开始专注。

**失联时不休闲。** 会动的画面看上去像还活着，正好与 `NO LINK` 相反。

**休闲不出声。** 语音在这台设备上是通知；一台桌上无缘无故哼歌的设备是骚扰，不是可爱。

**休闲不改变一眼可读的状态语义。** 顶部状态条保持值班时的空闲蓝，页脚照旧，睡着的精灵就等于“没有事等你”。

## 小剧目

无聊档随机演，不连着演同一出。全部用现有的方块、线条和字模画，8 fps。

| 剧目 | 内容 |
| --- | --- |
| 巡逻 | 走到右边，停下看你一眼，走到左边，再走回来。脚交替抬起 |
| 踢球 | 球从左边滚到脚边，一脚踢开，弹一下又滚回来，再一脚踢出画面。球始终在身体左侧，不穿过身体 |
| 看书 | 举着一本书一行行扫，隔五秒翻一页，中间被剧情吓一跳 |
| 数星星 | 夜色里几颗星闪，仰头数到七，越数越慢，数着数着睡着了 |
| 躲猫猫 | 溜到屏幕右边缘外只剩一只手在晃，探出半个身子看一眼，缩回去，最后走回来 |
| 被自己吓醒 | 睡着，突然一个感叹号跳起来，左右张望，打个哈欠，接着睡 |
| 梦话 | 睡着了，头顶冒出一串泡泡，泡泡里轮播今天的战绩 |

困倦档的底色是睡觉：闭眼、慢呼吸、一个飘起来的 `Z`，整个画面每个通道减半变暗。

## 昼夜与战绩

心跳里捎着 Mac 端的本地小时数（设备没有时钟，也不该为了这个去连 Wi-Fi）。夜里无聊档多演数星星和梦话、少巡逻踢球；不知道几点就当白天，宁可亮着也不要在下午关灯。

当日战绩里的完成数决定它的状态：今天一件没做，踢球的权重翻倍，无聊地踢石子；做了五件以上，累得梦多，困倦时不再被自己吓醒。梦话泡泡里念的就是战绩本身。

## K1 长按

长按 K1 一秒，氛围小助手立刻去休闲。这是给演示和验收用的：不必等五分钟。

## 实现

- 导演在 [`agent_leisure.c`](../firmware/main/agent_leisure.c)：无聊度、档位、剧目抽取、昼夜、战绩权重、熄灯判定，纯 C，不碰硬件。主机测试 `./tools/test-leisure.sh` 覆盖档位切换、活动清零、不连演、困倦只睡觉、熄灯只在夜里且有事即亮、计数回绕。
- 剧目绘制在 `agent_display.c`，氛围小助手参数化成可以指定位置、视线、眼睛、嘴、手臂、脚的姿势。`./tools/preview-display.sh` 把每个剧目渲染成 GIF，烧录前先看。
- 实机验收用时间压缩固件：`idf.py -B firmware/build-fast -DTIME_SCALE=60 build` 把五分钟压成五秒（番茄钟也同比压缩），几分钟内走完无聊、困倦、熄灯、被唤醒；`BUILD_DIR=firmware/build-fast tools/flash-bridge.sh <串口> partition app` 烧它。验收完再烧正式固件。
- 设备回报的诊断行：`MODE DUTY` / `POMODORO` / `LEISURE`，`LEISURE ALERT` / `BORED` / `SLEEPY`，`LEISURE SKIT <名>`，`LEISURE LIGHTS OUT` / `ON`，`CLOCK HOUR <n>`。
