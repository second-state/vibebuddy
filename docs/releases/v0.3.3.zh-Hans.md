## 新功能

- 角色：在新的「角色」页选择小助手是谁。Amanda、Jackson、湾湾小何和阿虎各有自己的外观、声音和台词；可以设置小助手怎么称呼你，也可以用几张图做一个自己的角色。
- 更新：Vibe Buddy 现在每天检查一次新版本（设置 → 通用）。固件单独发布并自动下载，设备页会提示更新。从这个版本起，Mac App 会通过自己的对话框完成自我更新。具体发送哪些信息，见 README 的「更新」一节。
- 安装后请在设备页更新盒子固件：角色功能需要固件 0.3.3。
- 盒子有了自己的菜单（长按 K1），音量改在那里调，App 里的音量滑块去掉了。设备页按原尺寸显示盒子屏幕。
- 旁边插着 Muse 开发板或其他 ESP32-S3 时，不会去打扰它。
