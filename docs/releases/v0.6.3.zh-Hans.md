## 新功能

- VibePlay 也能用 VibeBuddy：在“设备”页配对 VibePlay 后，它会显示和盒子一样的画面；agent 需要你时，即使你正在玩游戏，它也会提醒你。

## 修复

- Windows 上 Codex 的 WSL 工作区：VibeBuddy 的 Hook 不会再拦住 Codex；盒子上会显示会话名，按 K2 能跳回对应的会话。
- 在盒子的完成画面点任务卡片，就能打开刚完成的那个任务。
- 修复了 Codex 会话、“接入”页、“设备”页的一些小问题，以及更新固件后盒子设置显示不出来的问题。

## 更新前请注意

- 在 Windows 上用 Codex：这次更新会改写 VibeBuddy 的 Codex Hook，更新后需要在 Codex 的“设置 › Hooks”里重新信任一次。如果你同时用 Windows 和 WSL 工作区，两边要各信任一次。
- Linux（AUR）：更新后运行 `systemctl --user restart vibebuddyd`。用 `install.sh` 安装的会自动重启。
