## What's new

- A new look: the korekore App, on Mac and Linux, with the box in the sidebar.
- Sign in to a VibeBuddy account. You don't need one for the box, the agents or the Characters you have.
- Voice commands (Beta): turn them on in Settings → Conversation, then hold K0 on the box and ask. Your own Codex, or Claude Code with your own Anthropic API key, answers. Speech recognition uses your own Groq key, set in Settings → General. With your own ElevenLabs key, the buddy speaks the reply in the Character's voice; without one, the reply stays text.
- Make your own Character: write its lines and pick a voice, with your own ElevenLabs key.
- Firmware updates over Wi-Fi and the Relay, with no cable after this one.
- The box shows only the task cards from the computer it is linked to.
- Needs box firmware 0.6.0. Settings → Device offers it. From 0.5.0, plug in the cable for this update.
- Update VibeBuddy on every computer paired with the box: after the box has firmware 0.6.0, VibeBuddy 0.5.0 reaches it only over the cable.
- Linux (AUR): run `systemctl --user restart vibebuddyd` after the update. `install.sh` does this for you.
