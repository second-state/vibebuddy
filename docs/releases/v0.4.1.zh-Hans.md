## 新功能

- 支持 Pi：在「Agents」页接入后，盒子会像对待 Codex、Claude Code、OpenCode 和 GitHub Copilot CLI 一样播报它的任务。
- 新增英文角色 Dave：观点鲜明的丹麦程序员，讨厌复杂，凡事求简单。
- 在 Omarchy 上，VibeBuddy 的脸通过 [VibeBuddy 状态栏插件](https://github.com/second-state/omarchy-vibebuddy-plugin)显示在顶栏，取代托盘图标。
- Linux 版追上了 Mac 版：同样的「Agents」页（接入 / 修复 / 移除）、同样的角色和同样的设置。
- 名字统一写成一个词 VibeBuddy。Mac 上的应用改名为 VibeBuddy.app，已安装的「Vibe Buddy.app」第一次启动时会自动改名。
- 设置里的 daemon 版本号更短了。
