## What's new

Vibe Buddy now runs on Linux, tested on Omarchy (Arch, Hyprland).

- The daemon and the Claude Code / Codex hooks run as a systemd user service, and one installer sets it all up.
- A tray app with the Mac app's settings: volume, voices, agent connection, the box's screen, firmware updates, logs and diagnostics. It follows the Omarchy theme.
- K2 brings back the terminal window the session runs in, on any workspace.
- A desktop notification when the box disconnects.

Fixed on both platforms: screenshots and other commands no longer time out while the box is busy, and the box's firmware version is no longer missed after a reconnect.
