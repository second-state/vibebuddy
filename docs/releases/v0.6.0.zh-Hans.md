## 新功能

- App 全新外观，Mac 和 Linux 都有，侧边栏里有盒子。
- 盒子全新外观：可选 korekore 风格，也可以继续用机器人风格。
- 语音指令（体验版）：按住盒子上的 K0，直接问你的 Codex 或 Claude Code。插线、Wi-Fi、中转都能用，用的是你自己的密钥：Groq 负责听写；想让回答用角色的声音念出来，再填一个 ElevenLabs 密钥。
- 可以自己做角色：写台词、挑声音。
- 通过 Wi-Fi 和中转更新：固件和角色包不插线也能装到盒子上，断线后接着传，新固件起不来会自动退回旧版。
- 不插线的连接全程端到端加密。
- 带触摸屏的盒子：可以点菜单，点任务卡片打开对应的 Agent，还能摸摸伙伴。
- 任务卡片显示每个 Agent 的图标，最多两页，只显示当前连着盒子的那台电脑的任务。
- 可以登录 VibeBuddy 账号。不登录也能照常用盒子、Agent 和已有的角色。
- 其他：局域网里能按名字找到盒子，插线连接更稳，Wi-Fi 连不上会说明原因，还有很多小修复。

## 更新前请注意

- 需要盒子固件 0.6.0，设置 → 设备会提示更新。从 0.5.0 升级这一次要插线。
- 和盒子配对的每台电脑都要更新 VibeBuddy：盒子升到 0.6.0 固件后，VibeBuddy 0.5.0 只能插线连它。
- Linux（AUR）：更新后运行 `systemctl --user restart vibebuddyd`。用 `install.sh` 安装的会自动重启。
