## What's new

- VibeBuddy on VibePlay: pair a VibePlay on the Device page. It shows the box's screens and calls you when an agent needs you, even while you play.

## Fixes

- Codex on Windows in WSL workspaces: VibeBuddy's hook no longer stops Codex, the box shows the session's name, and K2 opens it.
- Tapping the card on the box's done screen opens the task that just finished.
- Small fixes for Codex sessions, the Agents and Device pages, and the box's settings after a firmware update.

## Before you update

- Windows with Codex: the update changes VibeBuddy's Codex hooks. Trust them again in Codex, in Settings › Hooks. If you use both Windows and WSL workspaces, trust them on each side.
- Linux (AUR): run `systemctl --user restart vibebuddyd` after the update. `install.sh` does this for you.
