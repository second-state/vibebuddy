## 新功能

- 支持 OpenCode 和 GitHub Copilot CLI：在「Agents」页接入后，盒子会像对待 Codex 和 Claude Code 一样播报它们的任务。
- 按 K2 直接回到会话所在的终端标签页，支持 Ghostty、Terminal.app、iTerm2、Warp 和 tmux。第一次使用时，在「Agents」页给对应的终端授权。
- 新增五个英文角色：Ada、Luna、Mei、Hank 和 Kai；每张角色卡都附上一句人设简介。
- 菜单栏新增「检查更新…」和「报告问题…」。报告问题会打开 GitHub 的新建 Issue 页面，并自动填好版本号。
- 播报更安静：配合 0.4.0 固件，几个任务在几秒内接连完成时只播报一次；同一次推送触发的多个 CI 工作流都会被跟踪，不会再漏报其中某个失败。
- 设置里的音量滑块回来了；同时插着多块开发板时，可以在「设备」页指定哪一个是盒子，也不会再给其他开发板推送盒子的固件。
