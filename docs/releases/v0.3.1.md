## What's new

- Opening Vibe Buddy while it's already running brings up Settings, with a Dock icon while the window is open. A second copy of the app no longer starts a second daemon.
- Settings → General has a Language option (English or 简体中文). When you switch, Vibe Buddy offers to switch the box's voice to that language too.
- If the Mac can't find the box, the app now tells you what to try: a data cable and macOS's "allow accessory" prompt first, then holding K0 while plugging in to flash it.
- Flashing a box that runs other firmware no longer fails with "Device or resource busy". After a flash, the app waits until the new firmware has really started, and asks you to replug the box if it hasn't.
- The Device tab no longer cuts off its last buttons.
