## What's new

- OpenCode and GitHub Copilot CLI: connect them on the Agents tab, and the box announces their tasks just as it does for Codex and Claude Code.
- K2 takes you to the session's own terminal tab, in Ghostty, Terminal.app, iTerm2, Warp and tmux. The first time, allow your terminal on the Agents tab.
- Five new English characters, Ada, Luna, Mei, Hank and Kai, and every character card now says in one line who they are.
- "Check for Updates…" and "Report a Problem…" in the menu bar menu. Reporting a problem opens a new GitHub issue with the versions already filled in.
- Quieter announcements: with firmware 0.4.0, tasks that finish within a few seconds of each other are spoken once. And every CI workflow a push starts is followed, so a failure in one of them is no longer missed.
- The volume slider is back in Settings. With several boards plugged in, you pick which one is the box on the Device tab, and other boards are no longer offered the box's firmware.
