## What's new

- Pi: connect it on the Agents tab, and the box announces its tasks just as it does for Codex, Claude Code, OpenCode and GitHub Copilot CLI.
- A new English character, Dave: an opinionated Danish developer who hates complexity and keeps it simple.
- On Omarchy, the buddy's face lives in the top bar through the [VibeBuddy bar plugin](https://github.com/second-state/omarchy-vibebuddy-plugin), in place of the tray icon.
- The Linux app catches up with the Mac: the same Agents tab with Connect / Repair / Remove, the same characters, and the same settings.
- VibeBuddy is now one word wherever the name shows. On the Mac the app becomes VibeBuddy.app; an installed "Vibe Buddy.app" renames itself the first time it starts.
- Settings shows a shorter daemon version.
