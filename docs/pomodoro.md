# 番茄钟场景

番茄钟是盒子上的第二个场景。第一个场景是小灯灵与任务卡，回答“Agent 现在怎么样”；番茄钟回答“我自己这一段专注还剩多久”。两者共用一块屏幕，所以需要场景这个概念；它们共用一只扬声器，所以语音不分场景。

## 时长

专注 25 分钟，休息 5 分钟，暂时固定。两个阶段都由用户按键开始，不自动衔接：专注结束后停在“休息待开始”（`BREAK 05:00`），按 K0 才开始计休息；休息结束后回到空闲，按 K0 才开始下一段专注。第一版曾让休息自动开始，理由是休息的意义在于被计时；实际用下来 dragon 要求改成手动——专注结束那一刻人往往还在收尾，休息从起身那一刻算才准。休息待开始时长按 K0 直接跳过休息回到空闲。

## 画面

复刻 Focus To-Do 的表盘：一圈 60 根刻度，走过的部分染成阶段色，一根更长的指针停在当前位置，倒计时放在圆心。空闲时指针停在 12 点、刻度全灰、显示 `25:00`。专注是番茄红，休息是绿色，空闲用小灯灵的 READY 蓝。

右栏三组信息：

- 阶段与按键提示：`FOCUS` / `BREAK` / `READY`，下面是当前可用的按键。暂停时倒计时数字每半秒闪一次，并额外显示 `PAUSED`——停表的老规矩。
- 完成计数：每完成一次专注记一格，开机后累计，重启归零。
- Agent 摘要：小灯灵的主状态与最上面那张任务卡的标题。番茄钟场景里 Agent 让出了画面，但没有让出注意力：需要确认时这一行仍然变黄，语音照常播。

切回小灯灵场景时，倒计时不消失：右上角有一个小徽章 `F 18:21` / `B 04:59`，暂停时同样闪烁。

失联时只灰掉 Agent 那一栏与顶部状态条。番茄钟是设备自己的事实，不因为 Mac 端失联而变得不可信，圆环保持原色。

## 按键

外壳上有 K0、K1、K2 三个键（另有 RST）。三个键各管一件事，与当前场景无关：

| 按键 | 短按 | 长按（1 秒） |
| --- | --- | --- |
| K0 | 番茄钟：开始 / 暂停 / 继续 | 放弃当前阶段，回到空闲；休息待开始时即跳过休息 |
| K1 | 切换场景 | 无 |
| K2 | 打开当前来源（上报 Mac，行为不变） | 无 |

每个键只有一种意思，不用记“在哪个场景里按什么”。专注途中 Agent 需要确认，按 K2 一下就能跳过去，不必先换场景。K0 开始一段专注时会自动切到番茄钟场景，圆环开始走就是反馈；暂停和继续不换场景，小灯灵场景右上角的徽章会跟着闪。

短按在松开时才算数，因为只有等到松开才知道它不是一次长按的开头。K2 上报 Mac 的时机因此从按下推迟到松开，对“打开来源”没有可感知的影响。

三个键的接线都已实机确认：K0 是 BOOT 键 GPIO0（PCB 丝印写作 `B0`），K1 是 XL9555 P0.4，K2 是 XL9555 P0.3，都是低电平有效。K1 的位是 2026-09-15 第一次烧录时由固件里的候选位探针定出来的：上游固件把 P0.0、P0.1、P0.4 与 P1.1～P1.7 配成输入，固件先把其中任一位变低当作 K1，实机按下时回报 `BUTTON RAW P0=0xEF`，随后收窄成单一位并去掉探针。

## 场景切换规则

- 用户用 K1 主动切换，设备记住他的选择。
- K0 开始一段专注时切到番茄钟。
- 阶段结束把番茄钟推到前面来。那一刻正是用户该看一眼的时候：知道该按键开始休息了，或者知道该按键开始下一段专注了。
- Agent 事件不抢场景。专注途中 Agent 需要确认，靠语音和右栏那一行黄字提醒；把画面切走等于替用户决定“Agent 比你的专注重要”，那不是设备该做的判断。

## 声音

专注结束和休息结束各播一次：先一段钟声，再一句中文语音。钟声是加法合成的（[`tools/make-pomodoro-audio.py`](../tools/make-pomodoro-audio.py)），专注结束是下行的“叮—咚”，休息结束是上行三音；语音是“专注结束，休息一下”和“休息结束”。钟声负责把注意力拉过来，语音负责说清楚是哪一个。

开始、暂停、继续、放弃都不出声：这些是用户自己按出来的动作，画面已经给了反馈。

## 状态归属

番茄钟的状态完全在固件里，`beacond` 不参与。它是设备 I/O 与确定性渲染，正是固件的职责；而且用户拿它计时的时候，Mac 端可能根本没在跑。固件只把转换以诊断行的形式发给 Mac（`POMODORO FOCUS START`、`FOCUS END`、`BREAK START`、`BREAK END`、`PAUSED`、`RESUMED`、`STOPPED`、`BREAK SKIPPED`），`beacond` 记进日志，不做别的。将来若要把番茄数记进当日战绩，再定义正式的设备到 Mac 事件。

## 验证

- 状态机有主机端测试：`./tools/test-pomodoro.sh`，覆盖开始、暂停、继续、放弃、阶段结束只报一次、毫秒计数回绕。
- 画面有主机端预览：`./tools/preview-display.sh`，把固件里同一份绘制代码渲染成 PNG，烧录前先看版式。
- 实机验收清单：按 K1 看到 `25:00` 表盘，再按 K1 回到小灯灵；按 K0 开始，画面自动切到番茄钟、指针走动，按 K1 切回小灯灵能看到右上角徽章；再按 K0 暂停，数字闪烁；长按 K0 回到 `25:00`；等到专注结束听到钟声加语音、画面自动切到 `BREAK 05:00` 且不走动；按 K0 休息开始走动；休息结束听到第二段钟声、回到 `READY`；专注途中让 Agent 请求确认，右栏那行变黄且语音照常，按 K2 能打开来源。
