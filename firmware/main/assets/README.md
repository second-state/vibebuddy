# 小灯灵语音资产

三个 PCM 文件由 macOS 的 `Tingting` 中文系统语音生成，再转换为 24 kHz、16-bit、双声道、小端序 PCM。它们只在以下状态切换时播放一次：

- `input_required.pcm`：需要你确认
- `done.pcm`：任务完成
- `failed.pcm`：任务遇到问题

工作中和空闲状态不播放语音，避免持续打扰用户。

三个文件以统一增益归一化到约 90% 满量程（2026-09-14，+5.5 dB，无削波）。合成后的原始素材峰值只有 41~48%，白白浪费了 6 dB 以上的动态范围。使用统一增益而非逐个归一化，是为了保持它们之间的相对响度。要再提高响度应优先调整 `agent_audio.c` 的 codec 音量，不要把素材推到接近满量程，那会让功放削波。
