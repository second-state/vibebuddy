# Buddy Voice Assets

The PCM files are 24 kHz, 16-bit, stereo, little-endian, generated in one step by `tools/make-voices.sh`. Each plays once, only on the following state changes:

- `input_required.pcm`: Hey, I need you for a sec.
- `done.pcm`: All done!
- `failed.pcm`: Uh-oh, something went wrong.
- `focus_done.pcm`: a chime, then "Nice work. Time for a break!"
- `break_done.pcm`: a chime, then "Break's over. Back to it!"
- `focus_chime.pcm`, `break_chime.pcm`: the two chimes alone, played before a Character's own Pomodoro line (the Rust firmware only; see `docs/characters.md`)

The working and idle states play no voice, to avoid constantly interrupting the user. Starting, pausing, resuming or abandoning a Pomodoro is silent too.

## Voice

The current voice is Jessica, one of ElevenLabs' own premade voices (`cgSgspJ2msm6clMCkdW9`, the `eleven_multilingual_v2` model, American female, switched on 2026-09-29), synthesized by `tools/elevenlabs-tts.py`. The project is going open source in English, so what you hear out of the box should be English; Chinese users can pick a Chinese voice in the app and write it into the `voices` partition. Checked-in audio must come from an ElevenLabs paid plan; the free plan doesn't include a commercial license.

The previous built-in voice was Wanwan Xiaohe (湾湾小何) from Volcano Engine's Doubao Speech (2026-09-16 to 2026-09-29); before that, the macOS system voice `Tingting` and Microsoft edge-tts's `zh-TW-HsiaoYuNeural` were used. Wanwan Xiaohe is still archived as an optional voice in `voices/wanwanxiaohe/`. API keys all live in the user's own environment and stay out of the repo. Synthesis happens only when generating the assets; the firmware doesn't depend on any online service at runtime. The finished output for every candidate voice is archived in `voices/` at the repo root; see the README there.

## Generating

```bash
# Generate into the voice library first, then copy here: each synthesis differs slightly, so this keeps both copies byte-for-byte identical
ELEVENLABS_API_KEY=... OUT_DIR=voices/jessica tools/make-voices.sh
cp voices/jessica/*.pcm firmware/main/assets/
```

The script normalizes each line individually to a -1 dBFS peak: synthesized peaks can differ by up to 1.7 dB between lines, so a single uniform gain would either clip one line or leave another too quiet. Converting mono to stereo loses 3 dB, so the script measures the peak after conversion. To make it louder, adjust the codec volume in `agent_audio.c` first rather than pushing the assets to full scale, which would make the amplifier clip.

The two Pomodoro files are produced by `tools/make-pomodoro-audio.py`, which prepends a chime to the speech; given no speech, it writes the chime alone (`tools/make-pomodoro-audio.py focus focus_chime.pcm`). The chime is generated by the script with additive synthesis and uses no third-party audio assets.
