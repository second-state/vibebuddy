# Vibe Buddy Rev A 硬件工程

状态：九页原理图草稿（总页 + 八个电路子页），已有 `.kicad_pcb` 初步布局，尚未布线，不可下单。用 KiCad 打开 `vibe-buddy-rev-a.kicad_pro`，再双击 `vibe-buddy-rev-a.kicad_sch` 进入总图；`VB.kicad_sym` 是本工程的元件符号库。

## 当前实现与验证

- 主控、USB、电源、三个业务按键与复位、BOX3 裸屏接口、音频采集、音频电源和音频播放已建立元件与跨页连接，共 105 个实体元件、100 个网络。
- 主控暂选 ESP32-S3-WROOM-1-N16R8；音频采用 ES7210、ES8311、NS4150B，功放使用稳压 3V3，不能直接承受 USB VBUS 的全部允许电压范围。
- 2026-09-18，KiCad 10.0.6 ERC 检查为 **0 错误、0 警告**，报告见 `erc-draft.rpt`。这是默认规则下的连接检查，不代表供电设计、器件参数或生产审核通过。
- 九页均能导出 SVG/PDF，已检查主控、显示、音频播放页的渲染并修正标签遮挡和页框重叠；尚未完成全部页面逐项人工复核。
- 从 KiCad 导出的 XML 网表核对了九组关键网络：USB 重复触点、原生 USB D+/D-、LCD SPI、差分扬声器输出及复位。已运行 PCB DRC，尚有未连接、工艺及丝印问题，不能放行。
- `circuit.py` 和 `build_schematic.py` 是生成源；重新运行会覆盖本目录原理图。若在 KiCad 内修改，须先保留修改并同步生成源，不能直接重新生成。

## 本轮电源审核与 PCB 布局

- 新增 TPS22918 受控上电，选择具体电感及布局封装；电源预算发现普通500mA端口不足以保证Wi-Fi/声音/亮屏峰值同时运行，待完成供电管理。
- 已生成四层90×80mm工程布局，105个电路元件和4个安装孔，所有原理图脚号在PCB上有对应焊盘；0条走线。板形为工程审查占位，不是最终产品尺寸。
- 完整审核、封装依据和未解决项见 [电源与封装审核](power-footprint-review.md)。DRC报告见 `drc-layout.rpt`：当前4项USB定位孔间距错误、2项天线区丝印越界警告，以及264项未连接。没有忽略这些报错或导出生产包。
- `build_layout.py`读取KiCad导出的`layout-input.xml`生成PCB，重新运行会覆盖布局；手动编辑前应保留副本。可双击 `vibe-buddy-rev-a.kicad_pcb` 查看。

## 已确定范围

ESP32-S3 模组、Wi-Fi、2.4 英寸屏幕、单模拟麦克风、ES7210 采集、ES8311 播放、NS4150B 功放、单扬声器。对外仅一个 USB-C、三个业务按键和一个复位键，无 TF 卡及扩展插座。暂按 USB 供电、无电池设计；暂不接模型。

完整设计输入见 [PCB 设计输入](../../docs/pcb-rev-a.md)。既有 BOX 和面包板固件继续保留，不能直接以其引脚分配代替本板设计。

## 工程推进顺序

1. 配置 KiCad 及官方符号/封装库，确定工程版本。
2. 落实完整采购料号与原厂规格书；自建封装须逐项核对焊盘尺寸、编号和方向。
3. 绘制原理图并做电源预算、引脚审查与 ERC；未定项不得用猜测的封装填充。
4. 结合屏幕和外壳装配确定板框；暂以四层板为设计方向，进入布局布线后复核。
5. 完成 DRC、机械核对、人工电路复核和可制造性检查后导出生产包。
6. 少量样机验收通过后再考虑 20～50 台试卖。

PCB 设计与工厂文件检查均不能代替实机功能验证。
