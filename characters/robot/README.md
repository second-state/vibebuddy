# Vibe Buddy, the robot

The default Character. Its look is drawn by the firmware itself, so there is no `look.png` and no `pack.bin` here: the App writes the robot as a pack without a look, with the voice and lines of the Character the user picks to lend them, or with the built-in voice's five fixed lines (`voices/jessica/`, packed as `robot`).

`face.png` is the robot on its idle frame, rendered by the firmware's host preview and halved, for the Character cards.
